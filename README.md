# M. Vinith Kumar - Premium Portfolio 🚀

A premium, modern, and fully animated personal portfolio website built with pure HTML5, CSS3, and Vanilla JavaScript.

## ✨ Features

### 🎨 Design System
- **Single Font**: Inter (exclusively)
- **Single Accent Color**: #0ea5e9 (Sophisticated cyan-blue)
- **Minimal & Professional**: Clean layouts with intentional whitespace
- **Responsive**: Pixel-perfect across all devices (320px - 1920px)

### 🌓 Theme Toggle
- ✅ Light & Dark themes
- ✅ Smooth transitions
- ✅ Respects system preferences
- ✅ Persists user choice in localStorage

### ⚡ Advanced Animations & Effects

#### Hero Section
- **Professional Image Showcase**: Your photo with elegant frame and glow effect
- **Floating Stats Cards**: Animated statistics with parallax movement
- **Slide-in Animations**: Staggered entrance for content and image
- **Parallax Scrolling**: Image moves subtly on scroll
- **3D Tilt Effect**: Image responds to mouse movement
- **Decorative Elements**: Floating gradient orbs

#### Navigation
- **Smooth Scroll**: Elegant scrolling to sections
- **Active Link Highlighting**: ScrollSpy navigation
- **Liquid Underline Effect**: Animated link indicators
- **Mobile Menu**: Smooth slide-in hamburger menu
- **Sticky Header**: Backdrop blur on scroll

#### Cards & Elements
- **Hover Tilt Effect**: 3D rotation on mouse movement
- **Shimmer Effect**: Light sweep across cards
- **Scale Animations**: Cards lift on hover
- **Ripple Effect**: Material Design-inspired button clicks
- **Magnetic Buttons**: Buttons follow cursor subtly

#### Interactive Features
- **Scroll Reveal**: Elements fade in as you scroll
- **Staggered Animations**: Sequential card appearances
- **Typing Effect**: Hero subtitle types out
- **Counting Animation**: Numbers count up when visible
- **Pulse Effects**: Status indicators and dots
- **Glow Effects**: Focus states with accent glow

#### Project Cards
- **Gradient Border Animation**: Animated top border
- **Hover Lift**: Cards elevate with shadow
- **Modal System**: Detailed project views
- **Smooth Transitions**: All state changes animated

#### Form & Contact
- **Focus Lift**: Inputs elevate on focus
- **Validation**: Real-time error feedback
- **Success Animation**: Slide-up success message
- **Loading State**: Animated spinner on submit

### 🎯 Performance
- **Pure Vanilla JavaScript**: No frameworks or libraries
- **Optimized Animations**: 60 FPS smooth performance
- **Lazy Loading**: IntersectionObserver for efficiency
- **Passive Listeners**: Optimized scroll performance

### ♿ Accessibility
- Semantic HTML5
- ARIA attributes
- Keyboard navigation

- Screen reader friendly

## 🚀 How to Use

1. **Local Development**
   - Simply open `index.html` in any modern browser
   - No build process required

2. **Customization**
   - Update personal information in `index.html`
   - Modify colors in CSS custom properties (`:root`)
   - Add/remove sections as needed

3. **Deployment**
   - Upload to GitHub Pages, Netlify, or Vercel
   - No special configuration needed
